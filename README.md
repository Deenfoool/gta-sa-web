# GTA SA Web — unofficial browser compatibility project

This project targets a static, client-side compatibility port for assets from a user's own original PC copy of GTA: San Andreas. No original game assets or binaries are distributed.

Current stage: M0/M1 local asset preflight; **not a playable GTA port yet**. Source-engine candidate: [OpenSA preserved fork](https://github.com/Avatarchik/opensa), AGPL-3.0-only. See `docs/ROADMAP.md` and `docs/UPSTREAM.md`.

This is an independent fan project and is not affiliated with Rockstar Games or Take-Two Interactive.
